# Ігри для Telegram-бота

Дві статичні гри, кожна — один `index.html` без збірки й залежностей (окрім
офіційного `telegram.org/js/games.js`). Рекорди зберігаються в `localStorage`
цього пристрою.

## Світлоблоки (`/`, short_name `svitloblocks`)

Падаючі ділянки в реєстрі за графіком відключень.

- Поле-«реєстр» 10 × 20: стовпці — черги відключень 1.1…5.2, рядки — години доби.
- Заповнений рядок зникає з написом «Ділянку зареєстровано», «Відомості внесено»,
  «Світло дали» чи «Витяг сформовано»; що 10 рядків — новий рівень і швидкість.
- Керування: кнопки на екрані, свайпи по полю (тап — поворот, різкий змах униз —
  миттєве падіння), на десктопі — стрілки, пробіл і P (пауза).

## Накладки (`/nakladky/`, short_name `nakladky`)

Пошук накладень ділянок.

- Рівні: «Пай» 9×9 (10 накладок), «Масив» 16×16 (40), «Кадастр» 16×30 (99).
  На вузькому екрані «Кадастр» стає вертикальним 30×16, а поле прокручується всередині.
- Перший хід завжди безпечний: накладки розкладаються після нього, і сусіди теж чисті.
- Тап — перевірити ділянку, довге натискання (400 мс) або перемикач «⚑ Спір» —
  поставити спір, тап по цифрі, коли спорів довкола стільки ж, — перевірити решту сусідів.
- «Накладок лишилось», «Строк розгляду», «Найшвидший витяг» (окремо для кожного рівня).

## Перевірка без браузера

```
node test/controls.test.js   # Світлоблоки: свайпи й кнопки
node test/nakladky.test.js   # Накладки: перший хід, акорд, програш, перемога, рекорд, дотики
```

## Розгортання

GitHub Pages (Settings → Pages → гілка `main`, коренева тека). Боту в `.env`:

```
GAMES=svitloblocks|Світлоблоки|https://yurii-kyselov.github.io/svitloblocks/,nakladky|Накладки|https://yurii-kyselov.github.io/svitloblocks/nakladky/
```
