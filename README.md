# Світлоблоки

Telegram-гра про реєстрацію земельних ділянок у графіку відключень. Один файл
`index.html`, без збірки й залежностей (окрім офіційного `telegram.org/js/games.js`).

- Поле-«реєстр» 10 × 20: стовпці — черги відключень 1.1…5.2, рядки — години доби.
- Заповнений рядок зникає з написом «Ділянку зареєстровано», «Відомості внесено»,
  «Світло дали» чи «Витяг сформовано»; що 10 рядків — новий рівень і швидкість.
- Керування: кнопки на екрані, свайпи по полю (тап — поворот, різкий змах униз —
  миттєве падіння), на десктопі — стрілки, пробіл і P (пауза).
- Рекорд зберігається в `localStorage` цього пристрою.

## Перевірка керування

`node test/controls.test.js` — свайпи й кнопки без браузера: один змах униз
роняє одну фігуру, повторне миттєве падіння раніше ніж за 150 мс не проходить,
утримання «вниз» не перескакує на наступну фігуру.

## Розгортання

Будь-який статичний хостинг, напр. GitHub Pages (Settings → Pages → гілка `main`,
коренева тека). Отриману адресу вписати боту в `GAME_URL`, а short_name гри з
@BotFather (`svitloblocks`) — у `GAME_SHORT_NAME`.
